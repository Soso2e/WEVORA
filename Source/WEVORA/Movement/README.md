# Inertial Mana Flight

実装済み・未確認。実入力、操作感、描画、アニメーション、カメラ、難易度の確認はユーザーがPIEで行う。

## 操作

| 操作 | 挙動 | マナ初期値 |
|---|---|---|
| 地上WASD | 通常移動 | 消費なし |
| 地上Space押下 | 上向き初速900 cm/sでジャンプ | 消費なし |
| 入力なし | ジャンプの上昇後、頂点付近で約1秒軽く浮き、0.35秒で通常重力へ戻って落下。水平慣性は残る | 消費なし |
| 空中WASD | 現在の上昇・落下速度を滑らかに抑え、高度を支えながら移動。ジャンプ初動の上向きの勢いは保持 | 8/秒 |
| Space長押し | 0.2秒の判定後、上昇速度1000 cm/sへ加速。空中での再押下は無料の二段ジャンプを発生させない | 18/秒（通常ホバー分を含む） |
| Ctrl押下・保持 | 即座に高度維持と浮遊を解除。上向き速度を切って下向き最低300 cm/s、その後強い重力で降下。WASD/Space/Altより優先 | 消費なし |
| Shift押下 | 水平速度を1800 cm/s追加、上限3200 cm/s。クールダウン0.45秒。速度上限が徐々に通常へ戻る | 12/回 |
| Alt保持 | 水平方向を減速し、空中ではマナで静止ホバー。WASD保持中でも減速。Space同時保持なら上昇、Ctrlなら降下が優先 | 8/秒（Space同時なら18/秒） |

- 空中WASDを離した後は0.2秒の入力猶予を設け、その間も高度維持分のマナを消費。その後は無消費の浮遊に移行する。
- マウスによる視点操作・魔法編みは飛行入力と扱わず、それだけで高度維持やマナ消費を発生させない。
- Shiftは空中で使用。Ctrl/Alt保持中、クールダウン中、マナ不足時は発動しない。発動しないクールダウン入力には消費なし。
- Ctrlを離すと、保持中のWASD/Space/Altはマナがあれば再び有効になる。入力がなければ通常落下を継続する。
- マナ不足時は残量を0へ減らして高度維持/加速を停止。飛行用マナは最大100、地上で20/秒回復。最後の消費から0.75秒待つ。空中回復は行わない。
- マナがなくても地上ジャンプは可能。Altはマナがなくても水平減速するが、落下は止めない。
- 操作解除・入力キャンセルでは保持状態を解除する。

## 調整場所

`BP_ThirdPersonCharacter`のClass Defaultsにある`WEVORA Movement`でジャンプ、浮遊時間、重力、マナ消費、上昇、Shift、ブレーキ、カメラを調整できる。最大マナ・地上回復は`ManaComponent`に設定する。Blueprintで以前から明示上書きした数値がある場合、その上書きが優先される。

旧方式の地面をTraceする自動ホバースプリングは廃止。地上はWalking、空中はFallingを用い、マナによる支えが有効な間だけ重力を打ち消す。これにより通常の床判定、着地、壁・天井とのsweep衝突を利用する。高度維持への切替では速度を瞬間的に0にせず、加速度上限内で減衰させる。

画面の仮フィードバックにマナと飛行状態を表示する。`Show Flight Feedback`で無効化可能。正式なHUDは`ManaComponent.OnManaChanged`、`Mana`、`GetManaRatio()`とCharacterの`FlightState`を参照できる。今回のマナは飛行用で、既存魔法のCastへの消費接続、専用UI、マルチプレイヤー同期は対象外。

## ユーザーによるPIE確認

Editorを開き直し、新しいC++クラスを読み込む。既存のThirdPersonレベルとキャラクターを使用でき、Blueprintの作り直しは不要。

1. Spaceを短く押す。勢いよく上がり、頂点付近でふわっとしてから自然に落下する。マナが減らず、着地すること。
2. WASDを保持したジャンプでも、最初の上向きの勢いが消えないこと。頂点付近で高度維持と消費が始まること。
3. 空中WASD移動、方向転換、入力終了を試す。入力猶予の後に消費が止まり、惰性を残して落ちること。視点操作だけではホバーしないこと。
4. Spaceを長押しし、継続上昇とマナ消費を確認。天井付近で押し続けた後に離しても、天井を抜けずに落下/移動できること。
5. 上昇中・移動中・Alt静止中にCtrl。即座に降下し、Ctrl保持中はSpace/WASD/Altで高度が支えられないこと。キーを押す順序も変えて確認。
6. 空中Shiftで強い加速を確認。次フレームに速度が急減しないこと、連打で上限を超えないこと。カメラFOVと旋回の操作感も確認。
7. Altで止まり、静止したまま魔法を編む。高度とマナ消費、右手エフェクト、既存Q/E/LMB操作が両立すること。
8. 空中でマナを使い切る。ホバー・上昇・Shiftが停止し、Altを押しても落下すること。着地後の回復と再ジャンプを確認。
9. レベルの端から歩いて落ちる、高速で壁へ当たる、坂への着地、低い天井、入力中のPIE終了・再開を確認。
10. 30/60/120 fpsでジャンプ頂点と浮遊時間、上昇・減速の差が気にならないか確認。
