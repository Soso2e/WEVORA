# Inertial Mana Flight

実装済み・未確認。実入力、操作感、描画、アニメーション、カメラ、難易度の確認はユーザーがPIEで行う。

## 操作

| 操作 | 挙動 | マナ初期値 |
|---|---|---|
| 地上WASD | 通常移動 | 消費なし |
| 地上Space押下 | 上向き初速900 cm/sでジャンプ | 消費なし |
| 入力なし | ジャンプの頂点・段差からの落下・入力解除後も通常重力（初期値1.2）で落下。水平慣性は残る | 消費なし |
| 空中WASD | 現在の上昇・落下速度を滑らかに抑え、高度を支えながら緩やかに加速（初期値550 cm/s²）。ジャンプ初動の上向きの勢いは保持 | 8/秒 |
| Space長押し | 0.2秒の判定後、上昇速度1000 cm/sへ加速。空中での再押下は無料の二段ジャンプを発生させない | 18/秒（通常ホバー分を含む） |
| Ctrl押下・保持 | 即座に高度維持と浮遊を解除。上向き速度を切って下向き最低300 cm/s、その後強い重力で降下。WASD/Space/Shift/Altより優先 | 消費なし |
| Shift押下・保持 | 押下時に水平速度を1800 cm/s追加、上限3200 cm/s。保持中は水平慣性を残してホバー。クールダウン0.45秒。保持によるダッシュ連発なし | 12/回＋保持中8/秒 |
| Alt保持 | 水平方向を減速し、空中ではマナで静止ホバー。WASD保持中でも減速。Space同時保持なら上昇、Ctrlなら降下が優先 | 8/秒（Space同時なら18/秒） |

- WASD/Shift/Alt/上昇の支え入力をすべて離すと、次の移動更新で通常重力に戻り、マナ消費が止まる。入力猶予・無入力時の浮遊は適用しない。
- マウスによる視点操作・魔法編みは飛行入力と扱わず、それだけで高度維持やマナ消費を発生させない。
- Shiftダッシュは空中で使用。Ctrl/Alt保持中、クールダウン中、マナ不足時はダッシュしない。クールダウン中でも保持ホバーはマナがあれば有効。地上で押して空中に移った場合はホバーだけ有効になり、自動ダッシュは発生しない。既存の`DoBurst()`は単発ダッシュのまま。保持を扱うBlueprint/UIは`DoBurstStart()` / `DoBurstEnd()`を使用する。
- Ctrlを離すと、保持中のWASD/Space/Shift/Altはマナがあれば再び有効になる。入力がなければ通常落下を継続する。
- マナ不足時は残量を0へ減らして高度維持/上昇/ダッシュを停止。飛行用マナは最大100、地上で20/秒回復。最後の消費から0.75秒待つ。空中回復は行わない。
- マナがなくても地上ジャンプは可能。Altはマナがなくても水平減速するが、落下は止めない。
- 操作解除・入力キャンセルでは保持状態を解除する。

## 調整場所

`BP_ThirdPersonCharacter`のClass Defaultsにある`WEVORA Movement`でジャンプ、空中加速、重力、マナ消費、上昇、Shift、ブレーキ、カメラを調整できる。最大マナ・地上回復は`ManaComponent`に設定する。Blueprintで以前から明示上書きした数値がある場合、その上書きが優先される。

主な調整項目:

| 項目 | 初期値 | 用途 |
|---|---|---|
| `AirSteeringAcceleration` | 550 cm/s² | 空中の加速・方向転換。従来2100の約26%。地上は既存`GlideAcceleration`を維持 |
| `CruiseSpeed` | 1200 cm/s | 通常の空中最高速度 |
| `FallGravityScale` | 1.2 | 無入力・マナ不足時の自然落下 |
| `VerticalVelocityDamping` | 4.5 | 入力中の落下減衰・ホバーへの追従速度 |
| `MaxHoverAcceleration` | 2200 cm/s² | 落下を受け止める加速度上限 |
| `HoverManaPerSecond` | 8/秒 | WASD/Shift/Altの高度支持の消費。複数同時でも重複消費しない |

旧`SteeringGraceDuration` / `PassiveFloatDuration` / `PassiveGravityScale` / `GravityReturnDuration`は保存済みBlueprintとの互換性のため残すが、移動に使用しない。Class Defaultsからは非表示。`Coasting`列挙値も互換性のため残すが、現在の移動では発生しない。

旧方式の地面をTraceする自動ホバースプリングは廃止。地上はWalking、空中はFallingを用い、マナによる支えが有効な間だけ重力を打ち消す。これにより通常の床判定、着地、壁・天井とのsweep衝突を利用する。高度維持への切替では速度を瞬間的に0にせず、加速度上限内で減衰させる。

画面の仮フィードバックにマナと飛行状態を表示する。`Show Flight Feedback`で無効化可能。正式なHUDは`ManaComponent.OnManaChanged`、`Mana`、`GetManaRatio()`とCharacterの`FlightState`を参照できる。今回のマナは飛行用で、既存魔法のCastへの消費接続、専用UI、マルチプレイヤー同期は対象外。

## ユーザーによるPIE確認

Editorを開き直し、新しいC++クラスを読み込む。既存のThirdPersonレベルとキャラクターを使用でき、Blueprintの作り直しは不要。

1. Spaceを短く押す。勢いよく上がり、頂点から通常の速度で落下する。マナが減らず、着地すること。
2. WASDを保持したジャンプでも、最初の上向きの勢いが消えないこと。頂点付近で高度維持と消費が始まること。
3. 空中WASD移動、方向転換、入力終了を試す。入力を離すと消費が止まり、惰性を残して通常重力で落ちること。視点操作だけではホバーしないこと。
4. Spaceを長押しし、継続上昇とマナ消費を確認。天井付近で押し続けた後に離しても、天井を抜けずに落下/移動できること。
5. 上昇中・移動中・Alt静止中にCtrl。即座に降下し、Ctrl保持中はSpace/WASD/Shift/Altで高度が支えられないこと。キーを押す順序も変えて確認。
6. 空中Shiftで強い加速を確認。次フレームに速度が急減しないこと、連打で上限を超えないこと。WASDなしでShiftを保持してもホバーすること、離すと通常落下になること、Ctrl優先・マナ不足でホバーが解除されること。カメラFOVと旋回の操作感も確認。
7. Altで止まり、静止したまま魔法を編む。高度とマナ消費、右手エフェクト、既存Q/E/LMB操作が両立すること。
8. 空中でマナを使い切る。ホバー・上昇・Shiftが停止し、Altを押しても落下すること。着地後の回復と再ジャンプを確認。
9. レベルの端から歩いて落ちる、高速で壁へ当たる、坂への着地、低い天井、入力中のPIE終了・再開を確認。
10. 30/60/120 fpsで空中加速・自然落下、上昇・減速の差が気にならないか確認。

## 開発側の自動確認

Editorビルドと`WEVORA.Movement`のHeadlessテストで、保存済みBlueprintの読込・移動コンポーネント継承、実World tick、床とのsweep着地、ジャンプ/自然落下、空中加速、マナ消費、入力解除、Ctrl優先、上昇、Shift速度維持/上限/消費/保持ホバー、Alt減速/直接ホバー、マナ不足と地上回復を確認する。公開入力APIを使用し、実キーボード・画面上の入力体験は検証しない。

## 魔法使用中の移動

- 通常 / Weaving / Shaping / ReadyToCastで、地上速度・巡航速度・操舵加速度を100 / 90 / 60 / 75%に変更。切替は0.2秒の補間。上昇速度・上昇加速度にも同じ倍率を適用し、高度維持の支えと重力は維持する。
- Shift / Ctrl入力時に編み途中の魔法をCancelし、Recoveryも解除。Shiftの追加速度・消費・クールダウンは既存どおり。Ctrl保持中に新しく編み始めても移動更新でCancelする。
- 発射成功後に0.15秒のRecovery。最初の0.04秒で35%へ滑らかに下げ、残り時間は維持し、終了後は現在の魔法状態へ0.2秒で戻す。壁に遮られた場合はRecovery・反動を発生させない。
- 発射方向と逆向きの水平反動を80 cm/s追加（Thrustは120 cm/s）。上昇・降下速度は変更しない。
- 弾は反動前のプレイヤー水平速度を40%継承。継承込みの速度を弾の上限に設定し、初回更新で継承分が切られないようにする。
- Characterの`WEVORA Movement|Spell`で移動倍率・補間・Recovery、`SpellCastComponent`の`Spell|Movement`で継承率・反動を調整する。

今回の環境にはUE 5.8本体がなく、Editorビルド・Automationテストは実行できていない。既存テストの期待値更新と30/60/120 fpsの回帰ケース追加、コードと差分の静的確認を実施。魔法状態の切替、Shift/Ctrl中断、Recovery、反動、高速飛行中の射撃の操作感はユーザーのPIE確認対象。
